GLOBAL DEPENDENCIES AND OWNERSHIP
---------------------------------
Backend engineers own Django feature contracts; QA/security independently check
tenant isolation and financial failure paths. Operators own environment secrets,
monitoring and recovery. The owner/business advisers own launch, suppliers,
tax/legal policy and money movement approval. These are responsibility roles,
not a claim that named personnel are already appointed.

Active Python dependencies: Django 5.2-range, Requests, psycopg[binary], Gunicorn,
WhiteNoise; see pyproject.toml for the actual supported ranges. PostgreSQL 16 is
the validated development database. SQLite bootstrap omits row-lock concurrency
coverage and is not equivalent. Docker Compose starts db/web/guarded worker.
No new provider SDK or parallel PHP backend is needed for these active features.

# Domain Reseller — official project

This is the official development repository for a branded domain reseller and web-services platform, aiming for GoDaddy/Namecheap-style customer experience and WHMCS-style business operations.

**Current status:** not a production-ready service. Development and safe provider sandbox verification are in progress.

Full source, onboarding documentation, roadmap, and developer checklists are being imported into this repository. During initial import, see the latest commit and GitHub Actions status.

**Safety:** Do not enable live payments or purchase domains before the owner's explicit approval and successful sandbox/security acceptance testing.
